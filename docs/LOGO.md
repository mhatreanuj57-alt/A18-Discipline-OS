# Daymark app icon

Daymark is the chosen public name for the native Android app previously called
A18 Discipline OS. The app icon combines a rising sun, an open planner and a
completion check. The sunrise suggests a fresh start; the check and open pages
make the daily planning purpose legible at launcher size.

The transparent PNG at `assets/daymark-logo.png` is also used as the adaptive
Android launcher foreground, splash mark and navigation header. It was generated
with the built-in image-generation tool on 20 October 2026. No personal data or
reference images were supplied. The adaptive icon background and Android 12+
splash retain the existing soft lavender Material surface.
