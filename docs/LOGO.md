# A18 Material-style logo

Created on 19 October 2026 using the built-in image-generation tool. This is an
original A18 identity inspired by Material 3 geometry, not Google's logo.

Project asset: `app/src/main/res/drawable-nodpi/logo.png` (1254 × 1254 RGBA PNG).
Used by the adaptive launcher icon and the native navigation header. A pale
lavender background keeps the indigo mark readable in both system appearances.
The website is unchanged. No user records were inputs to image generation.

## Generation prompt

Use case: logo-brand. Asset: finished native Android adaptive app icon foreground for A18 Discipline OS, a personal tasks and focus application using Google Material Design 3. Create a single original, exceptionally crisp flat geometric logo, transparent background. Exact lettering: "A18" only, clearly legible at tiny app-icon size; a rounded, substantial geometric A joined visually with compact rounded 18, with an understated check-shaped negative-space detail integrated in the A to suggest completing tasks. Primary color deep saturated indigo #4F378B with a restrained periwinkle #8C9EFF accent. Simple bold clean silhouette, balanced optical spacing, softly rounded strokes, confident friendly geometry, vector-like edges, no outlines or thin lines. One centered mark, generous transparent safe margin around every side, square image. No mockup, no phone, no shadows, no gradient, no texture, no tagline, no extra letters, no Google G, no Google wordmark, no surrounding badge or background square. It should feel at home beside modern Material 3 Android app icons while being an original A18 identity.
