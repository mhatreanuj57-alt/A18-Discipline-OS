# README artwork

The README uses eight PNG assets: the existing original A18 logo and seven new
feature illustrations in assets/readme. They are conceptual artwork, not app
screenshots, actual user records, analytics or evidence of additional app themes.

Generated on 19 October 2026 using the built-in image-generation tool. No app
database, screenshots, private records or external reference images were supplied.
The shared brief was a wide 3:2 Material 3 inspired editorial illustration with
crisp geometric rendering, rounded shapes, warm lavender #F7F2FA, indigo #6750A4,
lilac #EADDFF, small mint accents, generous margins and subtle tonal layering.
Each illustration uses its heading and a small A18 / MATERIAL STUDY caption.
No Google branding, people, photographic elements or fabricated progress metrics.

| File | Heading | Subject brief |
| --- | --- | --- |
| tasks.png | Tasks & progress | Checklist cards with separate start, complete and pending symbols. |
| planning.png | A plan for every day | Calendar grid, editable study blocks and book, without literal dates. |
| focus.png | Make time to focus | Circular timer, pause/play and task chips, without a numerical duration. |
| learning.png | Build skills steadily | Code strokes, Git branches and an open book, without vendor trademarks. |
| reminders.png | A gentle nudge | Two notification cards, bell and sound waves for start/end reminders. |
| local.png | Your device. Your records. | Phone, database and lock joined locally; no cloud or automatic-sync claim. |
| reflection.png | Reflect. Then reset. | Journal, pencil and review chips; no sensitive habit imagery or data. |

These images change the documentation only. The app's system light/dark appearance,
dynamic colors, screens, local records and packaged APK are unaffected.
